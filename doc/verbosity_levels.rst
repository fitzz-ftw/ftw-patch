Verbosity Levels
=================

.. list-table:: Verbositylevels
    :header-rows: 1
    :stub-columns: 1

    * - Level
      - Description
    * - 0
      - Total number of processed files.
    * - 1
      - Level 0 + total count of lines.
    * - 2 
      - Detailed count of created, modified, and deleted files (colorized).
    * - 3
      - Level 2 + total count of added and removed lines.
    * - 4 
      - Filenames of created, modified, and deleted files (colorized).
    * - 5 
      - Level 4 + file-specific line statistics (added/deleted).
    * - 6
      - Files + live line additions, deletions, and changes (colorized).
